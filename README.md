# AI 기반 결제 전 소비 후회 방지 서비스 기획서

## 1. 문제 정의

### 1.1 배경

- 온라인 쇼핑과 간편결제의 확산으로 사용자가 짧은 시간 안에 쉽게 상품을 구매할 수 있게 됨
- 할인, 광고, 개인화 추천 등으로 인해 계획하지 않았던 충동구매가 증가하고 있음
- 기존 가계부 및 핀테크 서비스는 주로 "얼마를 썼는지"를 분석하고 소비 내역을 사후에 보여주는 데 집중하고 있음
- 기존 커머스 추천 서비스는 사용자가 더 많은 상품을 구매하도록 유도하는 방향으로 설계되어 있음
- 사용자가 실제 결제를 진행하기 전에 "이 상품을 지금 구매하는 것이 합리적인가?"를 판단할 수 있도록 지원하는 서비스는 부족함

### 1.2 해결하고자 하는 문제

- 사용자가 상품을 결제하기 직전에 AI가 해당 구매의 필요성과 소비 부담을 분석
- 사용자의 과거 소비 패턴, 현재 예산, 구매 빈도, 유사 상품 보유 여부 등을 기반으로 구매 후회 가능성을 예측
- 구매하지 않는 것이 더 합리적인 상품을 AI가 탐지하여 사용자에게 알림
- 무조건 구매를 막는 것이 아니라 다음 세 가지 행동 중 가장 적합한 선택지를 제공
  - 구매 진행
  - 구매 보류
  - 대체 상품 선택
- 사용자가 반복적인 충동구매 패턴을 인식하고 장기적으로 소비 습관을 개선할 수 있도록 지원

---

## 2. 주제 선택 이유

- **AI Fintech** 분야에서 기존 소비 분석 서비스와 차별화된 새로운 방향의 서비스 구현 가능
- 기존 커머스 AI가 구매 전환율을 높이는 데 집중한다면, 본 서비스는 사용자의 **재정 건전성과 합리적인 소비**를 목표로 함
- 사용자의 결제 데이터, 소비 패턴, 예산, 구매 빈도 등을 활용하여 개인화된 AI 분석 가능
- 단순한 가계부가 아니라 **실제 결제 의사결정 순간에 AI가 개입**한다는 점에서 차별화 가능
- 소비자의 금융 건강(Financial Wellness)을 지원하는 서비스로 확장 가능
- AI의 역할을 "무엇을 살지 추천하는 것"에서 "무엇을 사지 않는 것이 좋은지 판단하는 것"으로 확장

## 3. 타겟 사용자

### 3.1 주 타겟

- 20~40대 온라인 쇼핑 및 간편결제 이용자
- 계획적인 소비 습관을 만들고 싶은 사용자
- 충동구매가 잦은 사용자
- 월별 생활비와 소비 예산을 관리하고 싶은 사용자

### 3.2 부 타겟

- 대학생 및 사회초년생
- 자취생 및 1인 가구
- 카드 및 간편결제를 많이 사용하는 사용자
- 재테크와 금융 관리에 관심이 있는 사용자

### 3.3 사용자 니즈

- "지금 이 상품을 사도 되는가?"를 빠르게 판단하고 싶음
- 충동구매를 줄이고 싶음
- 이번 달 예산을 초과하지 않고 소비하고 싶음
- 이미 가지고 있는 상품을 또 구매하는 것을 방지하고 싶음
- 비슷한 기능의 저렴한 상품을 찾고 싶음
- 단순한 소비 내역 확인이 아니라 실제 소비 행동을 개선하고 싶음

## 4. 서비스 개요

### 4.1 서비스 한 줄 소개

> **결제하기 전에 AI가 사용자의 소비 패턴과 재정 상황을 분석하여 "지금 사도 되는지" 판단해주는 개인 맞춤형 소비 의사결정 서비스**

### 4.2 핵심 서비스 흐름

    상품 선택
        ↓
    결제 직전
        ↓
    사용자 소비 데이터 분석
        ↓
    예산 및 소비 패턴 분석
        ↓
    유사 상품 및 과거 구매 이력 확인
        ↓
    충동구매 가능성 분석
        ↓
    구매 후회 가능성 예측
        ↓
    구매 적정성 점수 계산
        ↓
    ┌────────────┬────────────┬────────────┐
    │  구매 진행   │  구매 보류   │  대체 상품   │
    └────────────┴────────────┴────────────┘
        ↓
    사용자 선택
        ↓
    소비 결과 저장
        ↓
    AI 개인화 모델 업데이트

### 4.3 핵심 기능

#### 1. 결제 전 AI 소비 분석

- 사용자가 구매하려는 상품의 가격과 상품 정보를 분석
- 최근 소비 내역, 월별 예산, 구매 빈도 등을 함께 분석
- 결제 직전에 해당 구매의 적정성을 판단
- 별도의 복잡한 입력 없이 기존 결제 및 소비 데이터를 활용

#### 2. AI 구매 적정성 점수

사용자가 구매하려는 상품에 대해 **0~100점의 구매 적정성 점수**를 제공

예시:

    ┌────────────────────────────┐
    │      무선 이어폰            │
    │      가격: 129,000원        │
    │                            │
    │   구매 적정성               │
    │       38 / 100             │
    │                            │
    │   ⚠ 구매 보류 추천          │
    └────────────────────────────┘

    AI 분석 결과

    ✓ 현재 예산 대비 가격 부담 높음
    ✓ 최근 전자제품 지출 증가
    ✓ 최근 2개월 내 유사 제품 구매
    ✓ 과거 유사 제품 구매 후 반품 이력

#### 3. 구매 후회 가능성 예측

AI가 사용자의 과거 소비 데이터를 분석하여 해당 상품을 구매한 후 후회할 가능성을 예측

분석 요소:

- 과거 유사 상품 구매 이력
- 구매 후 환불 및 반품 이력
- 상품 가격 대비 평소 소비 수준
- 최근 동일 카테고리 소비 증가량
- 사용자의 월별 예산
- 구매 빈도
- 구매 시간대
- 충동구매 패턴

예시:

    구매 후회 가능성: 78%

    주요 원인
    - 최근 동일 카테고리 구매 증가
    - 평소보다 높은 가격
    - 현재 월 예산 여유 감소

#### 4. AI 구매 행동 추천

AI는 사용자의 상황에 따라 다음 세 가지 행동 중 하나를 추천

**구매 진행**

- 현재 예산에 부담이 적음
- 구매 빈도가 적음
- 기존 상품과 중복성이 낮음
- 사용자의 소비 패턴과 일치

**구매 보류**

- 충동구매 가능성이 높음
- 최근 동일 카테고리 지출이 많음
- 현재 구매 필요성이 낮음
- 예산 부족 가능성이 있음

**대체 상품**

- 현재 상품의 가격 부담이 높음
- 비슷한 기능의 저렴한 상품 존재
- 사용자의 가격 선호도와 맞지 않음

#### 5. 충동구매 탐지

사용자의 평소 소비 패턴과 다른 비정상적인 소비 행동을 AI가 탐지

분석 대상:

- 평소보다 갑자기 높은 금액의 결제
- 짧은 시간 내 연속적인 결제
- 새벽 시간대 반복적인 쇼핑
- 특정 카테고리의 갑작스러운 소비 증가
- 할인 및 이벤트 직후 급격한 구매 증가

예시:

    최근 2시간 동안

    결제 1 → 42,000원
    결제 2 → 73,000원
    결제 3 → 119,000원

    평소 소비 패턴 대비
    비정상 소비 가능성: 84%

    AI 추천:
    "추가 구매 전 24시간 보류를 추천합니다."

#### 6. 중복 소비 탐지

사용자가 이미 보유하거나 최근 구매한 상품과 현재 구매하려는 상품의 유사성을 분석

예시:

    현재 구매 상품
    무선 이어폰 A

    최근 구매 내역
    무선 이어폰 B
    구매일: 18일 전

    상품 용도 유사도: 94%

    "최근 구매한 상품과 용도가 매우 유사합니다.
    현재 보유 제품을 먼저 사용하는 것을 추천합니다."

#### 7. 예산 영향 분석

현재 구매가 사용자의 월별 예산에 미치는 영향을 계산

예시:

    현재 가용 예산: 650,000원
    상품 가격: 180,000원

    구매 후 예상 가용 예산: 470,000원

    이번 달 남은 기간: 12일
    예상 일평균 사용 가능 금액: 39,166원

    AI 판단:
    "구매 시 월말 예산 부족 가능성이 증가합니다."

#### 8. 구매 보류 타이머

AI가 충동구매 가능성이 높다고 판단하면 즉시 구매하지 않고 일정 시간 보류할 수 있도록 지원

    AI 추천

    "이 상품은 충동구매 가능성이 높습니다."

    [24시간 보류하기]

    24시간 후 알림:

    "어제 구매하려던 상품입니다.
    지금도 필요한 상품인가요?"

사용자가 다음과 같은 보류 시간을 설정할 수 있음

- 1시간
- 6시간
- 24시간
- 7일

#### 9. 소비 습관 리포트

주간 및 월간 단위로 사용자의 소비 행동을 분석

제공 정보:

- 총 소비 금액
- 충동구매 횟수
- 구매 보류 횟수
- 구매 보류 후 실제 구매하지 않은 금액
- 반복 구매 상품
- 카테고리별 소비 비중
- 예상 절약 금액
- 구매 후회 가능성이 높았던 소비
- 전월 대비 소비 변화

예시:

    [8월 소비 리포트]

    총 소비: 1,240,000원

    식비       32%
    쇼핑       28%
    교통       12%
    여가       15%
    기타       13%

    AI 분석

    ✓ 충동구매 7건 탐지
    ✓ 구매 보류 4건
    ✓ 실제 미구매 금액 218,000원
    ✓ 지난달 대비 불필요 소비 14% 감소

    이번 달 예상 절약 금액
    218,000원

#### 10. AI 소비 코치

AI 분석 결과를 단순한 숫자가 아니라 자연어로 설명

예시:

    사용자:
    "왜 이 제품을 사지 말라고 하는 거야?"

    AI:
    "최근 30일 동안 비슷한 용도의 제품을
    2개 구매했고, 이번 달에는 전자제품에
    평균보다 약 2배 많은 금액을 사용했습니다.

    현재 상품을 구매하면 이번 달 생활비가
    평소보다 부족해질 가능성이 있어
    7일간 구매를 보류하는 것을 추천합니다."

## 5. AI 기술 적용 방안

| 기능 | 적용 기술 | 설명 |
|------|-----------|------|
| 구매 후회 예측 | XGBoost / LightGBM | 과거 소비 및 구매 데이터를 기반으로 구매 후회 가능성 예측 |
| 소비 패턴 분석 | Clustering | 사용자의 소비 습관을 유형별로 분류 |
| 충동구매 탐지 | Anomaly Detection | 일반적인 소비 패턴과 다른 구매 행동 탐지 |
| 상품 중복 분석 | Embedding / Similarity Search | 기존 구매 상품과 현재 상품의 기능 및 용도 유사도 분석 |
| 예산 예측 | Time Series / Regression | 과거 지출 데이터를 기반으로 월말 예상 지출액 계산 |
| 대체 상품 추천 | Recommendation System | 가격, 기능, 선호도 등을 고려하여 대체 상품 추천 |
| 소비 코칭 | LLM | AI 분석 결과를 사용자가 이해하기 쉬운 자연어로 설명 |
| 구매 적정성 점수 | Ensemble Model | 예산, 소비 패턴, 상품 가격, 구매 빈도 등을 종합하여 점수 계산 |

### 5.1 구매 적정성 점수 산출

    사용자 데이터
          │
    ┌─────┼─────┐
    ↓     ↓     ↓
    소비   현재   구매
    패턴   예산   이력
    │     │     │
    └─────┼─────┘
          ↓
      AI 분석 모델
          ↓
    ┌─────┼─────┐
    ↓     ↓     ↓
    필요성 충동성 중복성
    분석   분석   분석
    │     │     │
    └─────┼─────┘
          ↓
     구매 적정성 점수
          ↓
       0 ~ 100점

### 5.2 AI 판단 예시

    사용자가 150,000원짜리 헤드폰을 결제하려고 함

                    ↓

    사용자 데이터 분석

    - 월 평균 취미 지출: 180,000원
    - 이번 달 취미 지출: 320,000원
    - 최근 30일 내 헤드폰 구매: 있음
    - 현재 가용 예산: 420,000원
    - 유사 상품 보유 가능성: 높음

                    ↓

    AI 분석

    구매 적정성: 31점 / 100점
    구매 후회 가능성: 76%

                    ↓

    AI 추천

    "구매 보류"

                    ↓

    추천 이유

    최근 유사 제품을 구매했고,
    이번 달 취미 지출이 평소보다 78% 증가했습니다.

                    ↓

    대안

    "현재 보유한 헤드폰을 먼저 사용하고
    7일 후 구매 여부를 다시 판단해보세요."

## 7. 기대 효과

### 7.1 사용자 측면

- 충동구매 감소
- 불필요한 중복 구매 감소
- 월별 예산 관리 편의성 향상
- 자신의 소비 패턴을 객관적으로 파악 가능
- 구매 후회 가능성이 높은 소비를 사전에 방지
- 장기적으로 건강한 소비 습관 형성

### 7.2 금융 측면

- 개인의 금융 건전성 향상
- 단순 지출 조회를 넘어 능동적인 금융관리 서비스 제공
- 금융사의 개인 맞춤형 Financial Wellness 서비스로 활용 가능

### 7.3 커머스 측면

- 단순 구매 전환 중심의 추천 서비스에서 벗어나 사용자 신뢰 기반의 서비스 구축
- 무조건적인 구매 유도 대신 고객의 장기적인 만족도 향상
- 반품 및 환불 가능성이 높은 구매 감소에 기여

### 7.4 비즈니스 측면

- B2C 구독 서비스
- 카드사 및 핀테크 기업 B2B API
- 쇼핑몰 결제 페이지용 AI 플러그인
- 금융사 자산관리 서비스와의 연계
- 개인 맞춤형 금융 코칭 서비스로 확장 가능

## 10. 서비스 핵심 가치

> **"무엇을 살지 추천하는 AI에서, 무엇을 사지 않는 것이 좋을지 알려주는 AI로."**

본 서비스는 사용자의 소비를 무조건 줄이는 것이 목적이 아니다.

사용자의 현재 재정 상황과 과거 소비 패턴을 분석하여 **구매해도 되는 소비와 잠시 멈춰야 하는 소비를 구분**하고, 사용자가 더 합리적인 소비 결정을 내릴 수 있도록 돕는 것을 목표로 한다.

최종적으로는 단순한 가계부나 상품 추천 서비스를 넘어,

> **"결제하기 전에 한 번 더 생각하게 만드는 개인 AI 금융 코치"**

로 발전하는 것을 목표로 한다.
